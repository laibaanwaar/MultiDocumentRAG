# Frontend Setup

This folder is a separate React + Tailwind CSS frontend for the Django backend.

## Install

```bash
cd frontend
npm install
```

## Run

```bash
npm run dev
```

## Build

```bash
npm run build
```

## Notes

- Vite is configured in `vite.config.js`
- Tailwind is configured in `tailwind.config.js` and `postcss.config.js`
- Entry files are in `src/main.jsx`, `src/App.jsx`, and `src/index.css`
